# UChicago Software Engineering Group

The UChicago Software Engineering Group exists to facilitate connections between staff, faculty, and post-docs at the University who spend a significant amount of time programming, whether for research, IT, or anything else.

The group meets on the second wednesday of every month at noon in John Crerar Library room 151. If you would like to join, [please fill out this form!](https://docs.google.com/forms/d/e/1FAIpQLSebIJIyCA1wU6-8l9YIzg7HmjIsft01vnauwaRbyPhfq-voXw/viewform?usp=header)


## Resources

- Our website is [uchicagosoftware.org](uchicagosoftware.org).
- Our slack channel is #uchicago-software-engineering-group in the CS Slack workspace. [Click here to join](https://cs-uchicago.slack.com/signup)
- If you have a topic you'd like to present on or be interested in seeing, please [please add it here!](https://docs.google.com/spreadsheets/d/1JWt_Fd_866s8R7t3RQCxnLkrv2ruQ-4agAm2fVMzokI/edit?gid=0#gid=0)! General discussion topics and plain/no slide decks are welcome!
- If you'd like to sign up to do a [cross team code review](https://github.com/uchicago-software/cross-team-collaboration/issues/new?template=review.yaml&label=unmatched) or [cross team planning/scoping/pointing session](https://github.com/uchicago-software/cross-team-collaboration/issues/new?template=planning.yaml&label=unmatched) or [browse open requests](https://github.com/uchicago-software/cross-team-collaboration/issues).
- We have a [shared google drive](https://drive.google.com/drive/folders/0ANIHvojRGqfFUk9PVA). Request access if you'd like to join!
- If you have something you'd like us to discuss, [add an issue to our agenda](https://github.com/orgs/uchicago-software/projects/1)
